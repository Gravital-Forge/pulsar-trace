**Epic:** PT-P8-E6

## Acceptance criteria

- `pulsartrace refine <input> --diarize-mic on|off` writes the sidecar before refining (so
  subsequent refines agree — PT-P8-R9); omitted flag = respect the existing stamp.
- MCP `request_refine` gains optional boolean `diarize_mic`: when present, writes the sidecar
  before enqueueing; response unchanged otherwise.
- The MCP recording-metadata surface (the tool that returns recording details — find it in
  `Sources/PulsarTraceMCP/`, the P6 read tools) reports `diarize_mic_stamp` (sidecar) and
  `mic_diarized` (last refine's metadata) per recording.
- The MCP manual text (`manual` tool) gains a short paragraph on the mic-diarization mode.

> **Mic diarization (in-person meetings).** Each recording carries a `diarize_mic` stamp
> (`options.json`). Stamp on ⇒ refine splits microphone speech into `You` (matched against the
