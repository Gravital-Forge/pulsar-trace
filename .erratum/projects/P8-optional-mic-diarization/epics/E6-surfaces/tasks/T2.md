# PT-P8-E6-T2 · Record-time stamping (app + CLI record path)

**Epic:** PT-P8-E6

## Acceptance criteria

- Starting a recording writes `options.json` into the new recording folder before the engine
  spawns, with `diarize_mic` = (CLI `--diarize-mic` flag) OR (app: `settings.diarizeMicEnabled`)
  (PT-P8-R2, PT-P8-R12).
- `RecordPlan.make(diarizeMic:)` (E4-T3) receives the same value, so the engine flag and the
  sidecar always agree at record start.
- Flipping the global toggle after recordings exist changes none of their sidecars (test).

  `Tests/UnitTests/RecordingOptionsTests.swift`

paths create folders in different places, write the sidecar in both, keeping the write a one-liner

- [ ] **Step 2: Implement flag + stamping**

`RecordCommand.Options` gains `let diarizeMic: Bool` (parse `--diarize-mic`, default false). In
the record run path, after the folder is created and before the engine spawns:

```swift
// PT-P8-R2/PT-P8-R12: stamp the recording at start; refines follow the stamp.
var recordingOptions = RecordingOptions.defaults
recordingOptions.diarizeMic = options.diarizeMic
try recordingOptions.write(to: recordingFolder)
```

and pass `diarizeMic: options.diarizeMic` into `RecordPlan.make`. The app path does the same with
`settings.diarizeMicEnabled` where it builds its plan/launch arguments.

- [ ] **Step 3: Immutability-of-existing-recordings test**

In `RecordingOptionsTests`:

```swift
@Test("the stamp is per-recording: another folder's stamp is untouched by later writes")
func stampsAreIndependent() throws {
    let a = tempDir(); let b = tempDir()
    defer { try? FileManager.default.removeItem(at: a)
            try? FileManager.default.removeItem(at: b) }
    var on = RecordingOptions.defaults; on.diarizeMic = true
    try on.write(to: a)
    try RecordingOptions.defaults.write(to: b)   // later recording, toggle now off
    #expect(RecordingOptions.read(from: a).diarizeMic == true)
    #expect(RecordingOptions.read(from: b).diarizeMic == false)
}
```
