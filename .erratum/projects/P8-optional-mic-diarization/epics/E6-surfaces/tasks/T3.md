- [ ] **Step 3: Detail-pane checkbox**

In the detail header (near the Refine affordance):

```swift
Toggle("Diarize microphone", isOn: Binding(
    get: { row.entry.diarizeMicStamp },
    set: { newValue in
        var options = RecordingOptions.read(from: row.entry.folderURL)
        options.diarizeMic = newValue
        try? options.write(to: row.entry.folderURL)
        paneModel.refreshEntry(folderURL: row.entry.folderURL)  // mirror title-edit refresh
    }))
    .toggleStyle(.checkbox)
    .disabled(row.isLive)
    .accessibilityIdentifier(A11yID.Recordings.diarizeMicCheckbox)
    .help("Applies on the next refine. Tick, then click Refine, to split "
        + "in-person speakers on your microphone — untick and refine to undo.")
```

`A11yID.Recordings`: `public static let diarizeMicCheckbox =
"pt.recordings.detail.diarizeMicCheckbox"`. The `refreshEntry` call: use whatever the rename flow
does to refresh a single row (pre-read note in Files) — do not invent a new refresh path.
