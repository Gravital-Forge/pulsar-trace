# PT-P8-E3-T3 · Merge tail + `metadata.json` evolution (schema v3)

**Epic:** PT-P8-E3

## Acceptance criteria

- `TranscriptAssembly.mergeStreams` labels mic segments per cluster when a mic attribution is
  supplied (via `DiarizationMerge.speakerLabels`, same overlap/co-attribution rules as the system
  stream); without one, mic segments stay `You` (today's behavior).
- `RefinementMetadata`: `currentSchemaVersion = 3`; new `micDiarized: Bool` field
  (`mic_diarized`); speaker rows: `isMicrophone == true` for every mic-channel speaker, `You` keeps
  `speakerId: nil`, mic guests carry their `spk_` ids (PT-P8-R10).
- `FinalMarkdownRewriter` metadata reconstruction passes `micDiarized` through unchanged (it
  already round-trips `schemaVersion` — extend the same way, lines ~381 and ~644).
- `assembleAndWrite` threads mic diarization + attribution end to end (queue path).

    var micLabels = DiarizationMerge.speakerLabels(
        for: dedupedMic, diarization: micDiarization)
    micLabels = micLabels.map { label in
        label.split(separator: "+")

        speakerIdByLabel[name] = id
