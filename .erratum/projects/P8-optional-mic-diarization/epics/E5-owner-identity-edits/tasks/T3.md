# PT-P8-E5-T3 · `demoteOwner` ("not me")

**Epic:** PT-P8-E5

## Acceptance criteria

- `SpeakerEditService.demoteOwner(recordingId:outputFolderRoots:)`:
  - reads the recording's `mic-diarization.json`; identifies the `You` cluster (the sidecar
    embedding best-matching the owner profile — same rule that attributed it, PT-P8-R4);
  - reconciles that embedding against the library (bestMatch ≥ threshold → existing speaker;
    else mint `Unknown #N` via the reconciler's numbering — reuse
    `SpeakerReconciler`/`nextUnknownName`, do not duplicate the numbering);
  - relabels the recording's `You` lines to the resolved name (scoped rewrite, reason
    `.ownerDemoted`); metadata row gains the `spk_` id, keeps `is_microphone: true`;
  - subtracts the sample from the owner profile (`remove(embedding:)`, E2-T2);
  - records the appearance on the resolved library speaker;
  - throws `EditError.micDiarizationUnavailable` without the sidecar; throws
    `EditError.noOwnerAttribution` when the recording has no `You` mic row in metadata.
- Events: `owner_demoted` (fields: `recording_id`, `speaker_id` of the resolved speaker,
  `applied_to_recordings`) before `final_md_rewritten`.

- [ ] **Step 3: Implement**

Same `editLock.run` frame as T2. Sequence:

```swift
public func demoteOwner(
    recordingId: String, outputFolderRoots: [URL]
) async throws -> EditResult {
    try await Self.editLock.run {
        guard let folder = Self.locateFolder(
                  recordingId: recordingId, in: outputFolderRoots),
              let micDiarization = MicDiarizationSidecar.read(from: folder)
        else { throw EditError.micDiarizationUnavailable }
        // Metadata must carry a You mic row (PT-P8-R6 inverse precondition).
        guard let metadata = try? JSONDecoder().decode(
                  RefinementMetadata.self,
                  from: Data(contentsOf: folder.appendingPathComponent(
                      RecordingFolder.FileName.metadata))),
              metadata.speakers.contains(where: {
                  $0.isMicrophone && $0.label == SpeakerEditService.microphoneSpeakerName })
        else { throw EditError.noOwnerAttribution }

        // The You cluster = sidecar embedding best-matching the profile.
        guard let ownerProfile,
              let ownerEmbedding = await Self.bestOwnerEmbedding(
                  in: micDiarization, profile: ownerProfile)
        else { throw EditError.noOwnerAttribution }

        // Reconcile-or-mint the demoted speaker.
        let resolved: Speaker
        if let match = try await library.bestMatch(
               for: ownerEmbedding, modelRevision: micDiarization.modelRevision) {
            resolved = try await library.recordAppearance(
                speakerId: match.speaker.id, centroid: ownerEmbedding,
                modelRevision: micDiarization.modelRevision,
                recordingId: recordingId,
                recordingFolderName: folder.lastPathComponent)
        } else {
            resolved = try await library.createSpeaker(
                name: try await Self.nextUnknownName(in: library),
                centroid: ownerEmbedding,
                modelRevision: micDiarization.modelRevision,
                recordingId: recordingId,
                recordingFolderName: folder.lastPathComponent)
        }

        try await ownerProfile.remove(embedding: ownerEmbedding)

        let appearance = try await library.appearances(of: resolved.id)
            .first { $0.recordingId == recordingId }!
        let results = try await rewriter.rewrite(
            oldName: SpeakerEditService.microphoneSpeakerName,
            newName: resolved.name,
            appearances: [appearance],
            outputFolderRoots: outputFolderRoots,
            reason: .ownerDemoted,
            remapSpeakerId: (from: "", to: resolved.id))   // see note below
        _ = try? await events?.append(OwnerDemotedEvent(
            recordingId: recordingId, speakerId: resolved.id,
            appliedToRecordings: results.map(\.recordingId)))
        await emitRewriteEvents(results, reason: .ownerDemoted)
        return EditResult(
            rewrittenRecordingIds: results.map(\.recordingId),
            resolvedSpeakerId: resolved.id)
    }
}
```

`EditResult` gains `public let resolvedSpeakerId: String?` defaulted `nil` in its init (every
existing construction compiles unchanged) — E5-T4's demote-undo consumes it.

Notes to resolve while implementing (each is a small, decidable point, not a design hole):
`bestOwnerEmbedding` = max cosine vs profile centroid, threshold `matchThreshold` — extract the
same selection T2 sketched and share it; the rewriter's `remapSpeakerId` remaps by *matching
existing id* — the `You` row has `speaker_id: null`, so remapping from `""` will not hit: extend
the rewriter's metadata step to set the id when relabeling `You → name` (a three-line addition
where `relabelled` is computed, ~line 613 — key it on `speaker.label == oldName &&
speaker.isMicrophone`); `nextUnknownName` — `SpeakerReconciler`'s is private: promote it to an

roots for a folder whose `metadata.json` has this `recording_id`; the rewriter has this logic —
share it).
