# PT-P8-E4-T2 · Mic label resolution in `LiveRunner`/`LiveSink`

**Epic:** PT-P8-E4

## Acceptance criteria

- With a mic diarizer present, `LiveSink.appendMicUtterance` no longer hardcodes `"You"`: the
  label resolves owner → library → `Guest`-family, mirroring the system stream's
  `resolveSystemLabel` (including the `?` pre-reconciliation suffix and the neutral no-coverage
  fallback).
- Owner resolution: the utterance's dominant mic `LiveSpeakerSpan` whose stitched centroid matches
  the owner profile at/above `OwnerVoiceProfileStore.matchThreshold` → `You` (no `?` — owner match
  is as strong as a library match).
- Without a mic diarizer (mode off), the path is exactly today's: label `"You"`, echo dedup first.
- Library/profile access is read-only (the profile handle is loaded once at pipeline start).

Next to `resolveSystemLabel` (~line 696), same structure:

```swift
/// PT-P8-R13 — mic twin of `resolveSystemLabel`: owner → library → Guest.
/// Owner match is revision-guarded (profile centroid usable only when the
/// live model's revision equals the profile's — PT-R112/PT-R113).
static func resolveMicLabel(
    spans: [LiveSpeakerSpan],
    utteranceStart: Duration, utteranceEnd: Duration,
    ownerCentroid: [Float]?, ownerRevision: String?, spanRevision: String?,
    libraryMatches: [String: String]
) -> String {
    guard let dominant = dominantSpan(   // reuse the system twin's overlap helper
        spans: spans, start: utteranceStart, end: utteranceEnd)
    else { return noCoverageLabel + "?" }
    if let ownerCentroid, let ownerRevision, ownerRevision == spanRevision,
       Centroid.cosineSimilarity(ownerCentroid, dominant.embedding)
           >= OwnerVoiceProfileStore.matchThreshold {
        return "You"
    }
    if let name = libraryMatches[dominant.provisionalKey] {
        return name   // apply the system twin's ? rule verbatim
    }
    return dominant.provisionalKey + "?"
}
```

`dominantSpan` — whatever the system path uses to pick the covering span; extract/share it rather
than duplicating.
