  start, keeping the live pass read-only and hop-free).

  `DiarizerEngine` load is reused for both adapters (`DiarizerEngineRawAdapter` per stream —
  verify the adapter/engine is safe to share; if it is stateful per stream, load one engine and
  wrap two adapters, which is the expected shape).
- `RecordPlan.make` gains `diarizeMic: Bool = false`: appends `--diarize-mic` to `engineArgs`.
- Mode off ⇒ all argv and behavior byte-identical to today (assert in `RecordPlan` tests).
