# PT-P7-E3-T4 · Merge + undo-toast round-trip

**Epic:** PT-P7-E3

The riskiest speaker flow the smoke checklist walks by hand: merge with its confirmation sheet, the
retroactive rewrite, the ~8 s undo toast, and a full restore on undo. Runs in the same
`SpeakerFlowTests` file as T3, reusing its helpers.

## Acceptance criteria

- Merging Carol into Alice: the confirmation sheet (`pt.speakers.mergeConfirm`) appears and is
  confirmed; the second seeded recording's `final.md` then labels Carol's utterance "Alice"; the
  events log carries `speaker_merged` before its `final_md_rewritten`.
- The undo toast (`pt.speakers.undoToast`) appears; clicking `pt.speakers.undoButton` restores the
  library (Carol's row returns) and the transcript ("Carol" back in the second `final.md`).

```swift
    func testMergeThenUndoRestoresLibraryAndTranscript() throws {
        let carolId = seed.speakerIds["Carol"]!
        let secondFinal = seed.outputRoot
            .appendingPathComponent(SeededHome.recordingFolders[1])
            .appendingPathComponent("final.md")

        // Select Carol, merge into Alice.
        let carolRow = app.descendants(matching: .any)["pt.speakers.row.\(carolId)"]
        XCTAssertTrue(carolRow.waitForExistence(timeout: 10))
        carolRow.click()
        let merge = app.descendants(matching: .any)["pt.speakers.mergeButton"]
        XCTAssertTrue(merge.waitForExistence(timeout: 10))
        merge.click()
        // The merge target picker/sheet: pick Alice, then confirm. The sheet
        // carries pt.speakers.mergeConfirm; the target row inside it is the
        // Alice row identifier.
        let aliceId = seed.speakerIds["Alice"]!
        let sheetAlice = app.descendants(matching: .any)["pt.speakers.row.\(aliceId)"]
            .firstMatch
        if sheetAlice.waitForExistence(timeout: 5) { sheetAlice.click() }
        let confirm = app.descendants(matching: .any)["pt.speakers.mergeConfirm"]
        XCTAssertTrue(confirm.waitForExistence(timeout: 10))
        confirm.click()

        // Rewrite lands on disk; cause precedes effect.
        try poll(timeout: 30, message: "merge rewrite") {
            let text = try String(contentsOf: secondFinal, encoding: .utf8)
            return (text.contains("Alice:**") && !text.contains("Carol:**"))
                ? true : nil
        }
        let types = try eventTypes(home: seed.home)
        guard let mergeIdx = types.firstIndex(of: "speaker_merged") else {
            return XCTFail("no speaker_merged event")
        }
        XCTAssertTrue(types.indices.contains {
            types[$0] == "final_md_rewritten" && $0 > mergeIdx
        }, "no final_md_rewritten after the merge cause")

        // Undo within the toast window restores library + transcript.
        let undo = app.descendants(matching: .any)["pt.speakers.undoButton"]
        XCTAssertTrue(undo.waitForExistence(timeout: 8),
                      "undo toast did not appear")
        undo.click()
        XCTAssertTrue(app.descendants(matching: .any)["pt.speakers.row.\(carolId)"]
            .waitForExistence(timeout: 10), "Carol did not return on undo")
        try poll(timeout: 30, message: "undo rewrite") {
            let text = try String(contentsOf: secondFinal, encoding: .utf8)
            return text.contains("Carol:**") ? true : nil
        }
    }
```

The merge sheet's internal structure (target picker shape, rewrite-count copy) is asserted only
through identifiers and disk effects — if the sheet exposes the target differently, attach the
missing identifier in the view (extend `A11yID.Speakers`) rather than falling back to text matching
(PT-P7-R3).
