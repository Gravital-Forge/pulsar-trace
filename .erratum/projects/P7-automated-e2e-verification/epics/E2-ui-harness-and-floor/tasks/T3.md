# PT-P7-E2-T3 · Wrapper project, `UITests/` scaffold, run script, launch smoke

**Epic:** PT-P7-E2

The harness itself (PT-P7-R5): expose the two library targets the mac sources import directly but
that have no SwiftPM product yet, commit the XcodeGen spec and the run script, and prove the loop
with one launch-smoke UI test. The generated `.xcodeproj` is already gitignored (`.gitignore:5`).

## Acceptance criteria

- `Package.swift` exposes `PulsarTraceMCP` and `PulsarTraceCapture` as library products (needed so
  the wrapper app target can link everything `Sources/pulsartrace-mac` imports); `swift build` and
  all test filters unchanged.
- `project.yml` generates an app target (same mac sources, ad-hoc signed, harness bundle id
  `com.gravitalforge.PulsarTrace.uiharness`) and a `bundle.ui-testing` target with a `UITests`
  scheme.
- `bash scripts/run-ui-tests.sh` builds the package (the app spawns
  `.build/debug/pulsartrace-engine` at record time — the resolver at
  `RecordingViewModel.swift:377-383`), generates the project, and runs the suite; extra arguments
  pass through to `xcodebuild` (e.g. `-only-testing:…`).
- The launch smoke passes: app launches on an isolated home, the status item appears.
- `.gitignore` also covers the generated `UITests/App-Info.plist`.

- [ ] **Step 2: Write the XcodeGen spec**

Create `project.yml`:

```yaml
# UI-test wrapper project (PT-P7-R5). Generated output (PulsarTraceUIHarness.xcodeproj)
# is gitignored — regenerate with `xcodegen generate` or scripts/run-ui-tests.sh.
# SwiftPM remains the only build system for shipped products; this project exists
# solely to compile the menubar app into a testable bundle and host XCUITest.
name: PulsarTraceUIHarness
options:
  bundleIdPrefix: com.gravitalforge
  deploymentTarget:
    macOS: "14.0"
packages:
  PulsarTracePackage:
    path: .
targets:
  PulsarTraceApp:
    type: application
    platform: macOS
    sources:
      - path: Sources/pulsartrace-mac
    dependencies:
      - package: PulsarTracePackage
        product: PulsarTraceMenuBar
      - package: PulsarTracePackage
        product: PulsarTraceEngine
      - package: PulsarTracePackage
        product: PulsarTraceMCP
      - package: PulsarTracePackage
        product: PulsarTraceCapture
    info:
      path: UITests/App-Info.plist
      properties:
        CFBundleDisplayName: PulsarTrace (UI Harness)
        LSUIElement: true
        NSMicrophoneUsageDescription: >-
          PulsarTrace records meeting audio for local, on-device transcription.
    settings:
      base:
        PRODUCT_BUNDLE_IDENTIFIER: com.gravitalforge.PulsarTrace.uiharness
        CODE_SIGN_IDENTITY: "-"
  PulsarTraceUITests:
    type: bundle.ui-testing
    platform: macOS
    sources:
      - path: UITests/PulsarTraceUITests
    dependencies:
      - target: PulsarTraceApp
      - package: PulsarTracePackage
        product: PulsarTraceEngine
      - package: PulsarTracePackage
        product: PulsarTraceMenuBar
schemes:
  UITests:
    build:
      targets:
        PulsarTraceApp: all
        PulsarTraceUITests: all
    test:
      targets:
        - PulsarTraceUITests
```

The harness bundle id is deliberately **not** `com.gravitalforge.PulsarTrace`: the test app must
never share the daily app's TCC grants or notification identity (PT-P7-R9). Ad-hoc signing
(`CODE_SIGN_IDENTITY: "-"`) is enough to launch locally and on CI.

- [ ] **Step 3: Write the run script**

Create `scripts/run-ui-tests.sh`:

```bash
#!/usr/bin/env bash
#
# Generate the UI-test wrapper project and run the XCUITest suite (PT-P7-R5).
# Extra arguments pass through to xcodebuild, e.g.:
#   scripts/run-ui-tests.sh -only-testing:PulsarTraceUITests/FloorTests
set -euo pipefail
cd "$(dirname "$0")/.."

command -v xcodegen >/dev/null 2>&1 || {
  echo "xcodegen not found — install with: brew install xcodegen" >&2
  exit 1
}

# The app under test spawns .build/debug/pulsartrace-engine (and -capture)
# through RecordingViewModel's default binary resolver — build them first.
swift build

xcodegen generate

mkdir -p .build/ui-test-results
exec xcodebuild test \
  -project PulsarTraceUIHarness.xcodeproj \
  -scheme UITests \
  -destination 'platform=macOS' \
  -resultBundlePath ".build/ui-test-results/$(date +%Y%m%d-%H%M%S).xcresult" \
  "$@"
```

Then: `chmod 755 scripts/run-ui-tests.sh`

- [ ] **Step 4: Write the launch smoke**

Create `UITests/PulsarTraceUITests/LaunchSmokeTests.swift`:

```swift
import XCTest

/// Harness proof (PT-P7-R5): the wrapper app launches on an isolated home
/// and surfaces its status item. Isolation only — no seeded state yet.
final class LaunchSmokeTests: XCTestCase {

    func testLaunchesIsolatedAndShowsStatusItem() throws {
        let home = FileManager.default.temporaryDirectory
            .appendingPathComponent("pt-ui-smoke-\(UUID().uuidString)")
        try FileManager.default.createDirectory(
            at: home, withIntermediateDirectories: true)
        defer { try? FileManager.default.removeItem(at: home) }

        let app = XCUIApplication()
        app.launchEnvironment["PULSARTRACE_HOME"] = home.path            // PT-P7-R1
        app.launchEnvironment["PULSARTRACE_DEFAULTS_SUITE"] =
            "com.gravitalforge.PulsarTrace.uitest.\(UUID().uuidString)"
        app.launch()
        defer { app.terminate() }

        // The MenuBarExtra label carries A11yID.statusItem (PT-P7-R3); fall
        // back to firstMatch if the identifier does not surface on the status
        // item itself on this macOS version — and if so, note it in the epic
        // completion record.
        let byId = app.statusItems["pt.statusItem"]
        let item = byId.waitForExistence(timeout: 15)
            ? byId : app.statusItems.firstMatch
        XCTAssertTrue(item.waitForExistence(timeout: 15),
                      "status item never appeared")
    }
}
```
