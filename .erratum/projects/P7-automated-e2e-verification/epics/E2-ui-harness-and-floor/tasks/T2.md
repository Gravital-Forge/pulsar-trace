# PT-P7-E2-T2 · Identifiers across the main window, live transcript, and speaker sheets

**Epic:** PT-P7-E2

The second attachment pass (PT-P7-R3): every surface and control the floor suite (T5) and the flow
suites (PT-P7-E3) drive inside the main window, the live-transcript window, and the speaker-flow
sheets/toasts. All constants already exist in `A11yID` (T1); this task only attaches them — if a
control the flows need turns out to lack a constant, add it to `A11yID.swift` first.

## Acceptance criteria

- Sidebar entries, the recordings list and its rows, the speakers list and its rows, the rename
  field, merge/delete controls, the merge-confirmation sheet's confirm button, the undo toast and
  its undo button, every Settings control named in `A11yID.Settings`, and the live-transcript window
  and list all carry their identifiers.
- Dynamic rows use the `row(_:)` helpers with the stable id (recording folder basename;
  `spk_<ulid>`), never a display name.
- No behavior change; `swift build` green. Enforcement is the floor suite (T5) and the E3 flows.


