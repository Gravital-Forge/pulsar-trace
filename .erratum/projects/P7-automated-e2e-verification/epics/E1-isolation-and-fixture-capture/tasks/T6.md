# PT-P7-E1-T6 · `RecordingViewModel` fixture mode

**Epic:** PT-P7-E1

Wire fixture capture through the start/stop state machine (PT-P7-R2): when the overrides carry
fixtures, `startRecording()` skips the TCC preflight, builds the fixture `RecordPlan`, and the
default factory picks `EngineOnlyOrchestrator`; the engine's self-exit at fixture EOF finalizes the
session like a user stop (auto-refine enqueued, `.idle`) instead of `.crashed`. The engine logs one
no-path line marking fixture capture.

## Acceptance criteria

- `RecordingViewModel` takes `overrides: EnvironmentOverrides = .current`; with fixtures set, a
  start runs no preflight (a denied-permission stub cannot block it), passes `RecordPlan.Fixtures`
  into the plan, and remembers the session is fixture-driven.
- `defaultOrchestratorFactory` returns `EngineOnlyOrchestrator` for a plan with empty
  `captureArguments`, the real `RecordOrchestrator` otherwise.
- Engine self-exit while `.recording`: fixture session → auto-refine enqueued, `.idle`,
  `resumeRefinement` called; device session → `.crashed` exactly as today.
- `stopRecording()` mid-fixture still works through the normal path (terminate + enqueue).
- The engine's live fixture branch logs `live session running from fixture capture` with no file
  paths (Hard Invariant #7).

    private func handleEngineExit(recordingId: String, partialFolder: URL) async {
        guard case .recording(let id, _) = status, id == recordingId else {
            return
        }
        crashWatch = nil
        orchestrator = nil
        liveMarkdownURL = nil
        // PT-P7-R2: a fixture session ends when the engine finishes the WAVs —
        // finalize exactly like a user stop, never as a crash.
        if currentSessionIsFixture {
            if let folder = currentRecordingFolder {
                await enqueueAutoRefine(folder, id)
            }
            currentRecordingFolder = nil
            status = .idle
            progressMessage = ""
            await resumeRefinement()
            return
        }
        status = .crashed(id: recordingId, partialFolderURL: partialFolder)
        progressMessage = "Recording stopped unexpectedly."
        await resumeRefinement()
    }
