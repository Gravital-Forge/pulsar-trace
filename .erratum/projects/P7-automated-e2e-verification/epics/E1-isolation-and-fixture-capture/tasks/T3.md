# PT-P7-E1-T3 · `MenuBarSettings`: overridable defaults suite and default output folder

**Epic:** PT-P7-E1

Settings are the remaining mutable surface outside `AppPaths`: they persist to the
`com.gravitalforge.PulsarTrace` `UserDefaults` suite, and their derived default output folder reads
the real `~/Documents`. Both consult `EnvironmentOverrides` so a test-launched app writes settings
to its own suite and records under the isolated home (PT-P7-R1, PT-P7-R9).

## Acceptance criteria

- With `PULSARTRACE_DEFAULTS_SUITE` set, a `MenuBarSettings()` constructed without an injected store
  persists to that suite, not the production suite.
- `MenuBarSettings.defaultOutputFolderURL` resolves to `<home>/Documents/PulsarTrace` under a home
  override; unchanged otherwise.
- A fresh overridden suite yields the safe test defaults PT-P7-R9 expects: `globalHotkey == nil`,
  `mcpServerEnabled == false`.

    /// Default output folder when the user has never chosen one:
    /// `~/Documents/PulsarTrace`, or `<home>/Documents/PulsarTrace` under the
    /// E2E home override (PT-P7-R1). Derived at read time and **never
    /// persisted** — clearing `outputFolderPath` re-defaults on the next read.
    public static var defaultOutputFolderURL: URL? {
        defaultOutputFolderURL(overrides: .current)
    }

    // PT-P7-R1
    public static func defaultOutputFolderURL(
        overrides: EnvironmentOverrides
    ) -> URL? {
        if let home = overrides.home {
            return home.appendingPathComponent(
                "Documents/PulsarTrace", isDirectory: true)
        }
        return FileManager.default.urls(
            for: .documentDirectory, in: .userDomainMask).first?
            .appendingPathComponent("PulsarTrace", isDirectory: true)
    }
