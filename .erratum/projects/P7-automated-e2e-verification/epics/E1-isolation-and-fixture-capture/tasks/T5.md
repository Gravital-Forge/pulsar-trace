# PT-P7-E1-T5 · `EngineOnlyOrchestrator`

**Epic:** PT-P7-E1

A minimal session driver for fixture capture (PT-P7-R2): spawns only `pulsartrace-engine`, without
the capture daemon or its `ready` handshake, and conforms to `RecordingOrchestrating` so
`RecordingViewModel` drives it interchangeably. Engine stdio goes to `/dev/null` — a filling,
undrained pipe blocks the child in `write()` (the P5 live-diarizer lesson); the engine's file log is
the observable channel.

## Acceptance criteria

- `public actor EngineOnlyOrchestrator: RecordingOrchestrating` in `PulsarTraceMenuBar`, built from
  `engineBinary` + `engineArguments`.
- `start` launches the engine (no readiness wait — the timeout parameter is unused);
  `waitForEngineExit` suspends until the process exits; `isEngineRunning` reflects liveness; `stop`
  terminates (SIGTERM) and awaits exit; all are safe to call after exit.
- A launch failure throws `RecordOrchestrator.StartError.engineLaunchFailed`.
- Tests drive it against stand-in `/bin/sh` scripts (the `RecordOrchestratorTests` idiom) — no real
  engine, no audio.

```swift
import Foundation
import PulsarTraceEngine

/// Drives a fixture-capture session (PT-P7-R2): spawns only
/// `pulsartrace-engine` — no capture daemon, no `ready` handshake — and
/// conforms to `RecordingOrchestrating` so `RecordingViewModel` treats a
/// fixture session exactly like a device session. The engine exits on its
/// own at fixture EOF; the view model turns that into a clean stop.
// PT-P7-R2
public actor EngineOnlyOrchestrator: RecordingOrchestrating {

    private let engineBinary: URL
    private let engineArguments: [String]
    private var engine: Process?
    private var exitTask: Task<Int32, Never>?

    public init(engineBinary: URL, engineArguments: [String]) {
        self.engineBinary = engineBinary
        self.engineArguments = engineArguments
    }

    /// Launch the engine. `readyTimeout` is unused — there is no capture
    /// handshake to wait for.
    public func start(readyTimeout: Duration) async throws {
        let process = Process()
        process.executableURL = engineBinary
        process.arguments = engineArguments
        // stdio → /dev/null: an undrained pipe blocks the child in write()
        // once full; the engine's file log is the observable channel.
        process.standardOutput = FileHandle.nullDevice
        process.standardError = FileHandle.nullDevice

        let (stream, continuation) = AsyncStream.makeStream(of: Int32.self)
        process.terminationHandler = { proc in
            continuation.yield(proc.terminationStatus)
            continuation.finish()
        }
        do {
            try process.run()
        } catch {
            throw RecordOrchestrator.StartError.engineLaunchFailed("\(error)")
        }
        engine = process
        exitTask = Task {
            var code: Int32 = -1
            for await c in stream { code = c }
            return code
        }
    }

    public func waitForEngineExit() async {
        _ = await exitTask?.value
    }

    public func isEngineRunning() async -> Bool {
        engine?.isRunning ?? false
    }

    public func stop() async {
        guard let engine, engine.isRunning else { return }
        engine.terminate()
        _ = await exitTask?.value
    }
}
```

Note: `RecordingOrchestrating` (declared in `RecordingViewModel.swift:11-20`) requires exactly these
four members; conformance is direct, no extension needed.
