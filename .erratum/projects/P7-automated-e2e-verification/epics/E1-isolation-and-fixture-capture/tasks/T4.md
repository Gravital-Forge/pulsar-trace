# PT-P7-E1-T4 · `RecordPlan.Fixtures` and the fixture argv variant

**Epic:** PT-P7-E1

`RecordPlan` stays pure argv derivation: a new optional `fixtures` input swaps the socket wiring for
the engine's existing fixture-source flags and empties the capture argv (PT-P7-R2). Engine semantics
to respect (see `Sources/pulsartrace-engine/main.swift:94-134`): the primary
`--source fixture <wav>` is the **system** stream (diarized labels); `--mic-fixture <wav>` pairs the
`You` mic stream. A lone mic fixture therefore rides as the primary single stream and comes out with
diarized labels, not `You` — acceptable for E2E, and documented on the type.

## Acceptance criteria

- `RecordPlan.Fixtures` is a `Sendable, Equatable` pair (`system`, `mic`), constructible only with
  at least one URL, plus `Fixtures.from(_ overrides:)` returning `nil` when fixture capture is
  inactive.
- `RecordPlan.make(…, fixtures: non-nil)` yields empty `captureArguments` and engine argv
  `--live --out <folder> --recording-id <id> --source fixture <primary>` (+ `--mic-fixture <mic>`
  when both set; + `--allowed-languages …` as today).
- `fixtures: nil` (the default) produces byte-identical plans to today — existing `RecordPlan` tests
  are the parity guard.

```swift
    /// Fixture WAVs standing in for the two capture streams (PT-P7-R2).
    ///
    /// Engine semantics: the primary `--source fixture` stream is the
    /// *system* stream (diarized); `--mic-fixture` pairs the `You` stream.
    /// With only `mic` set, that WAV rides as the primary single stream and
    /// its utterances get diarized labels rather than `You`.
    public struct Fixtures: Sendable, Equatable {
        public let system: URL?
        public let mic: URL?

        /// At least one stream is required.
        public init?(system: URL?, mic: URL?) {
            guard system != nil || mic != nil else { return nil }
            self.system = system
            self.mic = mic
        }

        /// The process overrides' fixtures; `nil` when fixture capture is
        /// inactive (the production path).
        public static func from(_ overrides: EnvironmentOverrides) -> Fixtures? {
            Fixtures(system: overrides.systemFixture,
                     mic: overrides.micFixture)
        }
    }
```
