# PT-P7-E4-T1 · Workflow skeleton: build-and-test + ui-floor

**Epic:** PT-P7-E4

The gating core of PT-P7-R6. Hermetic filters only — each in its own bare invocation (the broad
`PipelineTests` run is known-flaky cross-suite; CLAUDE.md); the UI job runs everything except the
model-dependent record flow.

## Acceptance criteria

- `.github/workflows/ci.yml` exists with `build-and-test` and `ui-floor` on `macos-15`, both gating;
  triggers: `pull_request`, `push` to `main`, `workflow_dispatch`; concurrency cancels superseded
  runs.
- `ui-floor` skips `RecordFlowTests` only, and uploads `.build/ui-test-results` on failure.
- The workflow is green on this branch's PR.

## Files

- Create: `.github/workflows/ci.yml`

- [ ] **Step 1: Write the workflow**

```yaml
# Hosted-CI verification (PT-P7-R6, PT-P7-D4): audio-independent tiers only.
# Real-audio capture never gates here — see scripts/e2e-audio-smoke.sh (dev host)
# and the non-gating probe job for the facts that could change that.
name: ci

on:
  pull_request:
  push:
    branches: [main]
  workflow_dispatch:

concurrency:
  group: ci-${{ github.ref }}
  cancel-in-progress: true

jobs:
  build-and-test:
    runs-on: macos-15
    timeout-minutes: 45
    steps:
      - uses: actions/checkout@v4
      - name: Swift version
        run: swift --version
      - name: Build
        run: swift build
      # One bare invocation per hermetic filter — never the broad
      # PipelineTests run (cross-suite fd races; CLAUDE.md).
      - name: Unit tests
        run: swift test --filter UnitTests
      - name: IPC suites
        run: swift test --filter IPC
      - name: Record orchestrator
        run: swift test --filter RecordOrchestrator
      - name: Live runner
        run: swift test --filter LiveRunner
      - name: Speaker suites
        run: swift test --filter Speaker
      - name: Source suites
        run: swift test --filter Source
      - name: Lifecycle
        run: swift test --filter Lifecycle
      - name: Final markdown rewriter
        run: swift test --filter FinalMarkdownRewriter
      - name: Menubar suites
        run: swift test --filter MenuBarTests

  ui-floor:
    runs-on: macos-15
    timeout-minutes: 45
    steps:
      - uses: actions/checkout@v4
      - name: Install xcodegen
        run: brew install xcodegen
      - name: UI suite (floor — no models)
        run: >-
          scripts/run-ui-tests.sh
          -skip-testing:PulsarTraceUITests/RecordFlowTests
      - name: Upload result bundle
        if: failure()
        uses: actions/upload-artifact@v4
        with:
          name: ui-floor-xcresult
          path: .build/ui-test-results
          if-no-files-found: ignore
```

Model-dependent filters (`Parakeet`, `WhisperKitRefine`, `FluidVAD`, `DiarizationE2E`, `Refinement`,
`Streaming`) are deliberately absent from `build-and-test`: they download model bundles and exercise
CoreML — that cost belongs to the cached `ui-flows` lane (T2), not to every PR's hermetic lane.
Device-gated `Capture` suites self-skip without `PULSARTRACE_DEVICE_TESTS` and are likewise not
invoked.

- [ ] **Step 2: Push and verify**

Push the branch and check both jobs on the PR: `build-and-test` green; `ui-floor` green with the
floor, launch-smoke, settings-persistence, and speaker-flow suites executed and `RecordFlowTests`
skipped. If an XCUITest interaction behaves differently on the runner's macOS than locally, fix the
query shape in the test — identifiers stay the locator (PT-P7-R3).

- [ ] **Step 3: Commit**

```bash
git add .github/workflows/ci.yml
git commit -m "ci: build + hermetic filters + UI floor on hosted macOS runners (PT-P7-R6)"
```
