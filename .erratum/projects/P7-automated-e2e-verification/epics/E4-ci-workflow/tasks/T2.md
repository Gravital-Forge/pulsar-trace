# PT-P7-E4-T2 · `ui-flows` job with the model cache

**Epic:** PT-P7-E4

The record → refine flow on CI (PT-P7-R6). The runner VM exposes no Neural Engine, so Parakeet and
WhisperKit run on CPU/GPU fallback — functionally identical output, much slower; hence a dedicated
job with the model cache and a long timeout, gating but isolated from the fast lanes (PT-P7-D4).

## Acceptance criteria

- A `ui-flows` job restores/saves `~/Library/Caches/PulsarTrace/models` under a versioned key,
  primes models on a cold cache via the two model-downloading filters, runs only `RecordFlowTests`,
  and uploads its `.xcresult` on failure.
- A warm-cache run performs no model download (verify in the job log).
- If the flow proves prohibitively slow on the CPU fallback (> ~30 min steady-state), do not loosen
  the test — record the timing in the epic completion record and raise demotion of this job to
  non-gating as a project decision.

## Files

- Modify: `.github/workflows/ci.yml`

- [ ] **Step 1: Add the job**

Append to `jobs:` in `.github/workflows/ci.yml`:

```yaml
  ui-flows:
    runs-on: macos-15
    timeout-minutes: 90
    steps:
      - uses: actions/checkout@v4
      - name: Install xcodegen
        run: brew install xcodegen
      - name: Restore model cache
        id: models
        uses: actions/cache@v4
        with:
          path: ~/Library/Caches/PulsarTrace/models
          # Bump the suffix when the pinned model set changes
          # (FluidAudio/WhisperKit versions in Package.swift).
          key: pt-models-${{ runner.os }}-v1
      - name: Prime models (cold cache only)
        if: steps.models.outputs.cache-hit != 'true'
        run: |
          swift test --filter Parakeet
          swift test --filter WhisperKitRefine
      - name: Record flow (fixture capture; CPU/GPU fallback — no ANE in VM)
        run: >-
          scripts/run-ui-tests.sh
          -only-testing:PulsarTraceUITests/RecordFlowTests
      - name: Upload result bundle
        if: failure()
        uses: actions/upload-artifact@v4
        with:
          name: ui-flows-xcresult
          path: .build/ui-test-results
          if-no-files-found: ignore
```

The priming step doubles as coverage: on a cold cache the two ANE-backend filters run on the runner,
verifying the CPU/GPU fallback end to end before the UI flow depends on it. `RecordFlowTests`
already points `PULSARTRACE_MODELS_DIR` at the host cache path this job restores.

- [ ] **Step 2: Push and verify twice**

Push and watch two runs: the first (cold) must download, prime, and pass; re-run the job (warm) and
confirm `cache-hit: true` with no download lines and a materially shorter wall clock. Note both
wall-clock times in the eventual epic completion record — they are the data PT-P7-D4's future
promotion/demotion decisions need.

