# PT-P6-E6-T3 · `speakers merge` / `delete` route through the service

**Epic:** PT-P6-E6

Route the remaining mutating `speakers` subcommands through the `SpeakerEditService` so they produce
the same file and event effects as the menubar and MCP paths (PT-P6-R9). `merge` gains the retroactive
rewrite; `delete` keeps its no-rewrite behaviour but now flows through the one shared service. `list`
stays a read and is unchanged.

## Acceptance criteria

- `speakers merge` calls `service.merge(...)` with the resolved roots and reports the rewrite count.
- `speakers delete` calls `service.delete(...)` (no rewrite).
- Smoke: `pulsartrace speakers merge … --output-folder <temp>` rewrites the merged label in the temp
  `final.md`.

## Files

- Modify: `Sources/pulsartrace/SpeakersCommand.swift`

- [ ] **Step 1: Route `merge` and `delete` through the service**

In `Sources/pulsartrace/SpeakersCommand.swift`, replace the `merge` and `delete` helpers (and their
dispatch calls) to use the `service` / `roots` from PT-P6-E6-T2:

```swift
    private static func merge(_ args: [String], service: SpeakerEditService, roots: [URL]) async throws -> Int32 {
        guard args.count == 2 else {
            err("usage: pulsartrace speakers merge <primary-id> <other-id> [--output-folder <path>]…")
            return 2
        }
        let result = try await service.merge(primaryId: args[0], otherId: args[1], outputFolderRoots: roots)
        out("merged \(args[1]) into \(args[0]) "
            + "(rewrote \(result.rewrittenRecordingIds.count) past transcript(s); "
            + "the merged speaker is soft-deleted, recoverable for 30 days)")
        return 0
    }

    private static func delete(_ args: [String], service: SpeakerEditService) async throws -> Int32 {
        guard args.count == 1 else {
            err("usage: pulsartrace speakers delete <speaker-id>")
            return 2
        }
        _ = try await service.delete(speakerId: args[0])
        out("deleted \(args[0]) (soft delete — recoverable for 30 days)")
        return 0
    }
```

Update the `switch` in `run` so `merge` / `delete` call these with `service` (and `roots` for
`merge`).
