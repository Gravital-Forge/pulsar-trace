# PT-P6-E5-T2 · `request_refine` — enqueue a refine and return immediately

**Epic:** PT-P6-E5

Enqueue a (re-)refinement of a recording and return immediately, without blocking on the pass
(PT-P6-R6). A `RefineRequesting` seam fronts the refinement job queue (in the app it forwards to
`RefinementJobQueueViewModel.enqueueManual`); the queue's own dedup makes a repeat enqueue a no-op.

## Acceptance criteria

- A `RefineRequesting` protocol exposes `requestRefine(folderURL:recordingId:) async throws`.
- `RecordingTools.requestRefine(recordings:refine:)` resolves the recording's folder, calls the seam,
  and returns immediately with a non-error result; a miss or missing argument errors.

```swift
import Foundation

/// Enqueue a (re-)refinement and return immediately (PT-P6-R6). The app forwards
/// to `RefinementJobQueueViewModel.enqueueManual`; the queue dedups so a repeat
/// enqueue for the same recording is a no-op.
// PT-P6-R6
public protocol RefineRequesting: Sendable {
    func requestRefine(folderURL: URL, recordingId: String) async throws
}
```

Add to `RecordingTools` (in `RecordingTools.swift`):

```swift
    // PT-P6-R6
    public static func requestRefine(
        recordings: any RecordingsProviding, refine: any RefineRequesting
    ) -> MCPTool {
        MCPTool(
            name: "request_refine",
            description: "Enqueue a (re-)refinement of a recording and return immediately. The refine "
                + "runs in the background; observe progress via recent_events.",
            inputSchema: .object([
                "type": .string("object"),
                "properties": .object(["id": .object(["type": .string("string")])]),
                "required": .array([.string("id")]),
            ])
        ) { args in
            guard let id = args?["id"]?.stringValue else {
                return ReadTools.errorResult("request_refine requires an `id`.")
            }
            guard let entry = await recordings.snapshot().first(where: { $0.id == id }) else {
                return ReadTools.errorResult("No recording with id \(id).")
            }
            do {
                try await refine.requestRefine(folderURL: entry.folderURL, recordingId: entry.id)
                return ReadTools.jsonResult(["status": "enqueued", "id": id])
            } catch {
                return ReadTools.errorResult("Could not enqueue a refine for \(id): \(error)")
            }
        }
    }
```
