# PulsarTrace transcript file format

The transcript files PulsarTrace writes (`live.md`, `final.md`, `metadata.json`) are a public API
surface. Their normative specification lives with the architecture:

→ **`.erratum/product/architecture/transcript-format.md`** (the `PT-C11 · Transcript Output`
contract).

A breaking change to the format bumps the major version and ships a migration note (PT-R89).
